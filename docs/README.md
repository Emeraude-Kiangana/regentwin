# RegenTwin Documentation

## Project role

RegenTwin is a Git-native provenance prototype for regenerative agricultural digital twins.

## Documentation map

- [Root README](../README.md) — Gate 0 invariant and run commands.
- [Project Status](PROJECT-STATUS.md) — evidence-based maturity snapshot.
- [Specification](../SPEC.md) — current Gate 0 specification.
- `regentwin/` — verifier implementation.
- `tests/` — state-chain verification tests.
- `twins/` — sample twin state chains.

## Gate separation

Gate 0 proves provenance-chain integrity only. Legal ownership, land-title validity, carbon-credit validity, RWA issuance and post-quantum security are separate future claims and must not be inferred from the current verifier.
